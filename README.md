# 🇧🇷 Português

Uma coleção de **CSS customizados** para personalizar a aparência de sites e serviços populares diretamente pelo navegador.

O projeto foi criado principalmente para ser utilizado com extensões de CSS personalizado, como o **Stylus**, mas os estilos também podem ser adaptados para outras ferramentas compatíveis com CSS.

## 🚀 Sobre o Projeto

O **CSS GERAL** reúne diferentes estilos personalizados em um único lugar, permitindo modificar a aparência de plataformas conhecidas sem alterar o funcionamento original dos sites.

Atualmente o projeto possui estilos para:

- 🐙 GitHub
- 🎵 Spotify
- ▶️ YouTube
- 💬 WhatsApp
- 💬 WhatsApp 2.0

Novos estilos, melhorias e atualizações podem ser adicionados futuramente.

## 🌐 Visualizar o Projeto

Acesse a versão online:

**css-geral.vercel.app**

## 🧩 Como Usar

A maneira mais simples é utilizando uma extensão que permita aplicar CSS personalizado em páginas da web.

### Usando Stylus

1. Instale a extensão **Stylus** no seu navegador.
2. Abra o site que deseja personalizar.
3. Abra o Stylus.
4. Crie um novo estilo para o site.
5. Escolha neste repositório o CSS correspondente.
6. Copie o código.
7. Cole dentro do Stylus.
8. Salve e atualize a página.

Pronto! 🎉

O novo visual deverá ser aplicado automaticamente.

# 🇺🇸 English

A collection of **custom CSS styles** designed to personalize the appearance of popular websites and services directly in your browser.

The project was mainly created to be used with custom CSS browser extensions such as **Stylus**, but the styles can also be adapted for other tools that support custom CSS.

## 🚀 About the Project

**CSS GERAL** brings together different custom styles in one place, allowing you to change the appearance of popular platforms without modifying their original functionality.

The project currently includes styles for:

- 🐙 GitHub
- 🎵 Spotify
- ▶️ YouTube
- 💬 WhatsApp
- 💬 WhatsApp 2.0

New styles, improvements, and updates may be added in the future.

## 🌐 Live Demo

Access the online version:

**css-geral.vercel.app**

## 🧩 How to Use

The easiest way to use these styles is with a browser extension that allows you to apply custom CSS to websites.

### Using Stylus

1. Install the **Stylus** extension in your browser.
2. Open the website you want to customize.
3. Open Stylus.
4. Create a new style for the website.
5. Choose the corresponding CSS file from this repository.
6. Copy the code.
7. Paste it into Stylus.
8. Save the style and refresh the page.

Done! 🎉

The new design should now be applied automatically.
