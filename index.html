Como Usar os Temas?

Instale seus estilos customizados em poucos passos simples usando extensões de navegador.

1

Instale o Stylus

Baixe e instale a extensão Stylus (ou UserCSS) no seu navegador (Chrome, Firefox, Edge, Brave).

2

Copie o Código ou Link RAW

Escolha um tema acima e clique em Ver Código para copiar a estrutura CSS ou copie a URL direta RAW.

3

Aplique e Aproveite

Crie um novo estilo no Stylus, cole o CSS e salve. A página correspondente atualizará o visual automaticamente!
